# stockpilot-api
Backend API for inventory management and purchase approval workflows built to showcase backend development skills.

## Goal
This project is being built to demonstrate backend development skills for junior software developer roles in Germany.

## Planned Tech Stack
- Java 21
- Spring Boot 3
- PostgreSQL
- REST APIs
- Docker
- GitHub Actions
- JWT Authentication

## Planned Features
- Product management
- Supplier management
- Warehouse management
- Inventory tracking
- Stock movements
- Purchase requests
- Approval workflow
- Role-based access control

## Status
Project setup in progress.
